# HardwareVS — приложения для ПК и Android

Приложения открывают ваш сайт https://vysotskiyxsamitov-gif.github.io/hardwarevs/
в своём окне. Сайт при этом менять не нужно: обновили сайт — приложения обновились сами.

## Как получить файлы (без установки программ)
1. На github.com создайте НОВЫЙ репозиторий, например `hardwarevs-app` (отдельный от сайта).
2. Загрузите в него всё содержимое этой папки (Add file → Upload files).
3. Файл сборки лежит в скрытой папке `.github`. Если она не загрузилась перетаскиванием:
   Add file → Create new file → в имени напишите `.github/workflows/build.yml`
   и вставьте туда содержимое файла `build.yml` из этого архива.
4. Откройте вкладку Actions → Build apps → Run workflow.
5. Через 5–10 минут внизу страницы запуска, в разделе Artifacts, появятся:
   - HardwareVS-Windows: установщик `HardwareVS-Setup-1.0.0.exe` и portable-версия без установки;
   - HardwareVS-Android: файл `app-debug.apk`.

## Установка
- Windows: запустите .exe (при предупреждении SmartScreen: «Подробнее → Выполнить в любом случае», у приложения нет платной подписи).
- Android: скопируйте .apk на телефон, откройте его и разрешите установку из этого источника.
